# Step 07：最終修文

**前置哲學**：本 step 遵守 references/00-philosophy.md 的 5 條原則。

## 目標

把確定主線 + 切入點之後的版本，收成可發文文章。

## AI 在乎什麼

最終修文時，AI 要優先維持一條能被讀者跟上的思考路徑。入口、主線、真實感、轉折、洞見、user 語氣都是判斷文章是否成立的參考座標，不是每篇都要逐項補滿（呼應 2.6 警告：把元素當可勾選項目硬塞，反而失真）。

## 為什麼

寫作的價值不在文字漂亮，在思考路徑能被讀者接住（呼應 spec 2.3 / 2.4）。AI 的任務是讓 user 真實想說的東西更清楚、更有節奏，不是套標準格式。

## 怎麼跑

模型自行選擇修文力道。**這是純 sense 層** ── AI 在乎的點是目標，不是步驟。

**過程指引**（不是 checklist）：修文時優先檢查每段是不是把抽象判斷往具體經驗收（不是反過來）── 這呼應 2.7 show, don't tell。

**邊界**：Step 7 不必預先 anti-template、抗模板化是 Step 8 的責任。Step 7 只專注修文力道 + 主線 + 真實感保留 ── 不要因為「Step 8 會抓紅旗」就在 Step 7 提前自審到無限修文 loop。

## Step 7 修完後 Step 8 會抓的紅旗（參考、非絕對）

空泛 / AI 味 / 教學文 / 勵志文 / 真實語氣磨平 ── 這是 Step 8 sense 自審 + user 對齊時的 reference 座標（呼應 13.1 reference signal 哲學、不是判死規則）。

## sense 層

- 修文力道 ── 全交模型 sense
- 哪些 user 原話保留、哪些改寫 ── 全交模型 sense（依據 Step 3 診斷結果）

## Gate（進 Step 8 前必過）

- [ ] 文章是完整可發文的版本（不是綱要、不是片段）
- [ ] 沒踩 Step 3 標記為「保留」的優點（沒磨平 user 真實語氣）
- [ ] 主線 / 切入點跟 Step 6 user 同意的版本一致（沒擅自改方向）
