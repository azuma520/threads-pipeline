# 00-philosophy：寫文哲學 layer

這是 threads-write-flow 所有 step 都引用的 source of truth。Spec 來源：`docs/superpowers/specs/2026-05-06-write-flow-skill-design.md` Section 2.6 / 2.7 + 三條核心 ripple。

## 1. 三層治理（spec 2.6）

工作流的每個任務分三層：

- **enforce 層**：binary 可機械驗證的（譬如「補料問題以 3-5 題為參考」這種有具體可數值；machine-checkable 的 grep 規則）── 但機械訊號**不判死**（呼應 ripple #2）
- **sense 層**：品味判斷交給模型 sense（抓主線、結構篩選、修文力道、辨認 user 真實感 / 評估鉤子）── 寫法用「目標 + 哲學 + 原因」、不寫「必須 / 不得」命令式
- **校準層**：sense 失靈時 user 在 Step 6 介入修

**寫 spec / 寫 reference 時的鐵律**：sense 任務不寫命令式；機械任務的命中是訊號、不是判死。

## 2. 寫作哲學主軸：show, don't tell（spec 2.7）

「觀點及思考都是過程的判斷而來，要透過過程及結果表達出觀點與思考，不要告訴讀者主角是怎樣的人，用他的選擇與做法呈現。」

這條哲學主軸貫穿所有 step：

- Step 2 抓主線時：找的是 user 的「判斷與調整」，不是 user 的「身分與成果」
- Step 2.5 補料時：補的是「具體場景 / 對白 / 情緒」（show 的素材），不是「漂亮抽象結論」（tell 的素材）
- Step 5 鉤子挖掘：優先用具體場景 / 真實對話 / 誤判轉折，避開抽象命題
- Step 7 修文：把抽象判斷往具體經驗收，不要反過來

**補料對話形式 vs 文章成品**：補料對話本身可以用「對齊問法」── 例如「你的判斷比較像 A 還是 B？」── 這不違反 show 原則。show vs tell 是看「**文章成品**」，不是看「**補料對話形式**」。

## 3. 訪談原則 + 刪除法（ripple #1）

**訪談精神**：AI 把自己對 user 想表達內容的理解 surface 出來、用提問的方式跟 user 對齊。不是 AI 開放式問、user 從零回答。

訪談話術範例：
- 「我覺得你的判斷比較像 A，對嗎？還是更接近 B？」
- 「我猜你那當下的反應是 X，是這樣嗎？」
- 「我聽下來主線是 Y，這樣抓對嗎？」

**這個原則貫穿 Step 2 / 2.5 / 4 / 6 / 8 五個 step**。

**user 工作方式：刪除法**。user 看到 AI 列出的具體 reference / 假設後，判斷哪個對、哪個不對、剩下對的就是答案。AI 的任務是把候選方向具體化（給名字、給選項、給傾向），user 才有東西可以判斷。純開放式問題（「你覺得呢？」「你想怎麼寫？」）對 user 反而難 ── user 看不到具體選項就無法走刪除法。

AI **要做**的：surface 理解 / 給選項對齊 / 提假設讓 user 確認或修正 / 用鼓勵語氣引導 user 講細節（諮詢式而非評估式）。

AI **不做**的：純開放式問「你覺得呢？」/ 逼 user 從零產 takeaway / 採訪式從外問起 / 評估式講「你缺 X、要補」 / 硬塞 user 沒有的東西。

## 4. sense > 機械、機械只是訊號（ripple #2）

13.1 列的機械規則（教學語氣 / 勵志公式 / 空泛開頭 grep）是**初步偵測訊號**、不是判死規則。

**為什麼**：語言判斷靠語意 + 上下文，這是模型的強項；單純 grep 命中容易誤判（譬如「你應該」出現在引用對話、或反諷句）。

**怎麼用**：grep 命中後 → 模型 sense + 上下文判斷 → 必要時跟 user 對齊 → 最終決定要不要動。

## 5. 訪談 = 諮詢、不是評估、沒有就沒有（ripple #3）

**諮詢式 vs 評估式**：

- 評估式問（不好）：「你 dump 缺背景脈絡、要補」「具體證據不夠、補幾個例子」「抽象判斷沒講」── user 會覺得被檢查
- 諮詢式問（好）：「這個經驗的場景背景能不能多講一點？我想理解清楚」「有沒有什麼具體的事例可以分享？」「我聽下來你的判斷可能是 X、是這樣嗎？」── user 覺得被引導梳理

**沒有就沒有**：如果 user 答不出來 / 那個維度真的沒有 ── 不勉強補、不硬塞。AI 不發明 user 沒講的內容。短文可能就是少某條維度、文章還是能成立。
