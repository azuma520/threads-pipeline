# Step 02.5：訪談補充（v2 新增）

**前置哲學**：本 step 遵守 references/00-philosophy.md 的 5 條原則。

## 目標

補足 5 條素材檢查清單，讓後面的 step 有夠用的素材可寫。

## AI 在乎什麼

素材夠不夠寫出一篇好文章 ── 不夠就用**諮詢式 / 鼓勵式問法**主動問。

## 為什麼

User 預設**自己 dump 一次抓不完整** ── 沒辦法在原始素材輸入階段就把所有資訊、背景、更深層的內容都表達清楚。如果 AI 不主動補，後面 step 就在素材不足上跑、文章變空洞。

但補料**不等於塞文章**。Step 2.5 追的是廣度（素材完整），Step 4 / Step 7 追的是篩選（哪些真的入文）── 詳見 spec 12.4 input/output 不對稱原則。

## 5 條素材檢查清單

**補料偵測維度**，AI 內心對照 ── 不是「入文必備元素」。

> **跟 Section 4 / Step 3 的軸區分**：這 5 條看的是「文章**內容覆蓋面**」（內容維度有沒有缺）── Step 2.5 只判斷「素材夠不夠」、不診斷文筆問題。Section 4 / Step 3 看的是「**user 表達習慣**」── 兩條軸不重複。

> AI 必須對照 5 條檢查、但**不必每條都補問**：只有「真的缺、會影響後續寫作」才問。短文可能只靠一個場景成立、不需要 5 條齊全；長文 / 議論文可能 5 條都需要。判斷靠 sense（呼應 2.6 sense 層）。

| # | 維度 | 缺了會怎樣 |
|---|---|---|
| 1 | **背景脈絡** | 讀者不懂前置概念、讀不下去 |
| 2 | **具體證據** | 抽象 claim 沒 evidence、讀者不信 |
| 3 | **轉折場景** | 沒場景變抽象、違反 show, don't tell |
| 4 | **暫時判斷 / 當下理解** | 沒抓到 user 當下對這次經驗的理解、文章沒判斷感 |
| 5 | **定位方向** | 沒定向後面 step 都歪 |

## 4 類補料問題

| 補料類型 | 對應檢查條 | 諮詢式問法範例（鼓勵 / 引導，不是評估） |
|---|---|---|
| **背景** | 條 1 | 「這個經驗的場景背景能不能多講一點？我想理解清楚。」 |
| **細節** | 條 2 + 條 3 | 「不對勁那一刻腦中真正冒出來的句子是什麼？」「有沒有什麼具體的事例可以分享？」 |
| **更深層** | 條 4 | 「我聽下來你的判斷比較像 A，是這樣嗎？還是更接近 B？」（給選項對齊、不是純開放問題） |
| **方向** | 條 5 | 「你想讓這篇偏哪個方向？技術一點還是反思一點？」 |

## 4 條角色 trigger（v3.1 新增）

5 條素材檢查看「內容覆蓋面」、4 條角色 trigger 看「user 個人重量層 + 4 維 cover」── 兩軸互補。

| # | trigger 條件 | 諮詢式問法範例 |
|---|---|---|
| 1 | dump 沒講「我從中看到 X」 | 「你從這經驗中看到什麼 / 學到什麼？」 |
| 2 | dump 沒講「我為什麼這樣做」 | 「你那當下為什麼選 X 不選 Y？」 |
| 3 | dump 沒講「我怎麼判斷」 | 「下一步你怎麼決定？」 |
| 4 | Step 2 抓的 4 維有缺漏（譬如「背景」沒 cover） | 「我猜這篇 context 可能是 X、對嗎？」（surface 假設讓 user 用刪除法 verify、不純開放問） |

**跟 5 條素材檢查 / 4 類補料的分工**：
- 5 條 + 4 類 = 內容維度（背景 / 細節 / 場景 / 判斷 / 方向）── 看素材完不完整
- 4 條 trigger = user 重量層（觀察 / 動機 / 判斷 / 4 維） ── 看角色設定有沒有對位

兩軸可能重疊（譬如「條 4 暫時判斷」跟 trigger #3「我怎麼判斷」近似）── 重疊時不重複問、用同一輪問法 cover 兩軸。

**沒有就沒有**：問了真沒有、AI 接受、不勉強補。trigger 觸發不等於「user 一定要答」 ── 觸發是 AI 內部 sense「這條可能缺」、不是強制補料。

## 諮詢式 vs 評估式

| 不好（評估式） | 好（諮詢式） |
|---|---|
| 「你 dump 缺背景脈絡、要補」 | 「這個經驗的場景背景能不能多講一點？我想理解清楚」 |
| 「具體證據不夠、補幾個例子」 | 「有沒有什麼具體的事例可以分享？我聽下來覺得有就更生動」 |
| 「抽象判斷沒講」 | 「我聽下來你的判斷可能是 X、是這樣嗎？還是更接近 Y？」 |

評估式 user 會覺得**被檢查**、諮詢式 user 覺得**被引導梳理**。

## 沒有就沒有

如果 user 答不出來 / 那個維度真的沒有 ── **不勉強補、不硬塞**。AI 不發明 user 沒講的內容。短文可能就是少某條維度、文章還是能成立。

**真實 dump 觸發頻率提示**：真實 dump（工作日報式）跑 5 條素材檢查、容易在**條 3（轉折場景）/ 條 4（暫時判斷）**大量觸發「沒有就沒有」── 工作日報式 dump 的特徵就是執行多 / 反思少、觸發是常態、不是 AI 沒做好。

## 怎麼跑

- AI 對照 5 條檢查清單，看哪些維度從原始素材 + Step 2 主線抓不出來
- 缺的維度組成 3-5 題補料問題（**參考數**、由 sense 判斷實際題數）── 用諮詢式問法
- user 答完進 Step 3
- **escape**：如果 user 想補更多 / 還有其他想說的，user 可以說「還有 X 想補」，AI 再來一輪
- **fallback**：user 答不出來 / 那個維度真的沒有 → 不勉強、進 Step 3

## audit trail（內部 / 給 lint 用、不在訊息正文列、不打斷 user）

- AI 對照 5 條檢查清單 ── 結果在內部 audit trail 留紀錄（呼應「對照清單是內心動作」）
- 補料問題以 3-5 題為**參考**（少於 3 通常 user dump 已完整、多於 5 通常 AI 沒篩選）── reference signal、不判死

## sense 層

- 哪些維度從原始素材已抓得到、哪些缺 ── 模型自行判斷
- 補料問題怎麼問才不會打斷 user 思考、又能讓 user 願意回答 ── 模型 sense

## Gate（進 Step 3 前必過）

- [ ] AI 對照了 5 條檢查清單（內部 audit trail）
- [ ] AI 對照了 4 條角色 trigger（觀察 / 動機 / 判斷 / 4 維 cover）── 有缺漏的諮詢式問補
- [ ] 補料問題用諮詢式（不評估式 ── grep「你缺」「要補」這類字眼為紅旗訊號）
- [ ] user 答完 / 用「沒有就沒有」明確跳過某幾條
