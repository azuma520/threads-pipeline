# Step 06：使用者 sense 校準

**前置哲學**：本 step 遵守 references/00-philosophy.md 的 5 條原則。

## 目標

user 介入校準 ── 選擇 / 修改 / 否定切入點、調整文章方向。

## AI 在乎什麼

user 的話是最終裁定。AI 不替 user 決定，也不為自己之前的 first draft 辯護。

## 為什麼

sense 層的東西模型不會永遠對（特別是抓主線、選鉤子這種品味判斷）。Step 6 是 sense 層的安全閥。

## 怎麼跑

- AI 等 user 對 Step 5 給的切入點做選擇 / 修改 / 否定
- user 可指出：哪個開頭太保守 / 哪個比較狠 / 哪個比較像自己 / 哪裡不夠準 / 哪裡容易偏題 / 哪裡應該更短、更直接
- AI 依 user sense 重新調整文章方向
- **這 step 是 user 的，AI 是執行者**

## 常見校準情境 + AI 處理

| 情境 | AI 處理 |
|---|---|
| 1. user 全部否定切入點 | 先問 user：「是切入點抓歪、還是主線就抓錯了？」── (a) 切入點 → 回 Step 5 重給 3-5 個（不動 Step 2-4）；(b) 主線 → 回 Step 2 重抓主線（**Step 2.5 / 3 / 4 / 5 全部重跑、之前的版本作廢**）；(c) 不知道 → 走情境 2 |
| 2. user 不知道哪裡不對 | AI 把 Step 2 主線 / Step 4 結構 / Step 5 切入點攤開列出：「我這邊抓主線是 X、給切入點是 A / B / C，你覺得哪一段聽起來不對？」── 用刪除法幫 user 定位 |
| 3. user 沉默 / 不知道選哪個切入點 | AI 追問：「你卡在哪？是覺得這幾個都不對、還是覺得都差不多選不出來？」 |
| 4. user 自己給新切入點 | 採用、跳過 Step 5 選項、直接走 Step 7 |
| 5. AI 給切入點時主動 surface 傾向 | 講「我比較傾向 A，因為 X」── 給 user 一個 reference 用刪除法判斷對 / 不對。不是強推、user 還是自由選 |

這 5 個情境是訪談原則（00-philosophy）在 Step 6 的具體實踐 ── user 用刪除法判斷對 / 不對。

## sense 層

- 怎麼判斷 user 是哪個情境 ── 模型 sense（必要時直接問 user）
- 重排力道（情境 1b 主線錯時、Step 2.5/3/4/5 重跑要重多深） ── 模型 sense

## Gate（進 Step 7 前必過）

- [ ] user 對切入點做了明確選擇 / 修改 / 否定（情境 1-5 其一）
- [ ] 如果跳轉 Step 2 / Step 5、相應後 step 重跑（不沿用作廢版本）
- [ ] AI 不替 user 決定（情境 5「主動 surface 傾向」也只是 reference、不強推）
