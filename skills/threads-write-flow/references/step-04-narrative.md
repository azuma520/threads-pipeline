# Step 04：初步結構重排（敘事草稿）

**前置哲學**：本 step 遵守 references/00-philosophy.md 的 5 條原則。

## 目標

把素材排成有閱讀路線的草稿。

## AI 在乎什麼

讀者能順著走 ── 知道這篇在談什麼、事件與觀點不互相干擾、背景只服務主題、文章有自然的心理或認知轉折。

## 為什麼

原始素材的順序通常是 user dump 順序，不是讀者讀順序。Step 4 是把它重排成讀者順序的草稿。**這 step 不必追求最強鉤子**（那是 Step 5），也不必追求最終文字（那是 Step 7）。

## Step 4 vs Step 7 邊界

- Step 4 = **敘事邏輯**（素材怎麼編排、段落怎麼串得通）── 用 user 原話 OK、不必修文
- Step 7 = **文字邏輯**（句子怎麼寫得精、語氣怎麼對齊）── 拿 Step 4 草稿去修

## 怎麼跑

Step 4 解決「敘事邏輯」、不解文字精煉（後者是 Step 7）。AI 把原始素材 + Step 2.5 補料用敘事邏輯串成「能讀的草稿」── 不是 outline / bullet 綱要、也不是最終文章。Step 4 結束 user 介入校準（B 模式 + Human-in-the-loop，呼應 10.6 訪談原則）。

## 輸出格式（4 點 enforce + 1 條 optional）

1. **敘事草稿 3-6 段**（已串成有邏輯的草稿、用 user 原話 OK、不必修文）
2. **每段編排理由**（為什麼這段擺這、為什麼那段擺那 ── 讓 user 用刪除法判斷編排對 / 不對）
3. **每段使用哪些素材**（從 user dump + Step 2.5 補料對應到段）
4. **不確定點標記**（AI 跑的時候有「兩種排法都合理、選不出來」── 在 surface 草稿時順便 flag「這段我選 X、但 Y 也合理、你決定」）
5. （optional）**哪些補料暫時不入文** ── 留紀錄方便 Step 6 / Step 7 review

**重排力道交模型 sense**（保留哪些 / 砍哪些、怎麼讓認知轉折自然發生）── 但輸出格式 enforce 上述 4 條（第 5 條 optional）。

## user 介入訪談話術

surface 草稿 + 編排理由 + 不確定點之後，AI 用訪談語氣邀請 user 校準（呼應 10.6）：

「**這版我這樣編：第一段 X（理由 ...）、第二段 Y（理由 ...）...、不確定點 [...]。你看哪一段不對 / 哪一段順？**」── user 用刪除法判斷。

三條路：

- 全部 OK → 走下一步（Step 5 鉤子）
- 部分要動 → user 標哪段 / 哪邊不對、AI 重排該段
- 整個方向不對 → AI 先問 user：「**是這幾段排序的問題、還是主線本身就不對？**」── (a) 排序問題 → AI 重排（不動 Step 2）；(b) 主線錯 → 回 Step 2 重抓主線（**Step 2.5 / 3 / 4 / 5 全部重跑、之前的版本作廢**）

## 篩選原則（呼應 spec 12.4 input/output 不對稱）

每個進入文章的素材必須能對應到「**主線 / 轉折 / 洞見**」的某個錨點。如果一段素材只是 Step 2.5 補料時 user 答出來的、但對主線沒有錨點，這段不入文 ── 不是「為了用而用」。鉤子 / 開頭的篩選留到 Step 5 再做。

## sense 層

- 重排力道、保留哪些 / 砍哪些、怎麼讓認知轉折自然發生 ── 全交模型 sense
- 「不確定點」的判斷 ── 模型 sense（沒把握的就 flag）

## Gate（進 Step 5 前必過）

- [ ] 輸出包含 4 點 enforce 格式（草稿 3-6 段 / 編排理由 / 每段素材 / 不確定點）
- [ ] 用訪談語氣 surface 給 user（不是純丟草稿）
- [ ] user 同意 / 部分要動 / 跳轉重跑 三條路其一明確發生
