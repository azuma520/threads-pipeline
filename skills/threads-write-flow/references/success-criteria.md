# success-criteria：成功標準

**前置哲學**：本 doc 遵守 references/00-philosophy.md 的 5 條原則。

成功標準分兩組 ── **機械訊號的**（初步偵測）跟 **sense 自審的**（user 是裁判）。

## 13.1 機械訊號部分（Step 8 反模板化檢查的初步偵測，不是判死規則）

下列規則 grep 命中**只是「需要看上下文判斷」的訊號**、不是「命中即不合格」。最終由 sense（語意 + 上下文）+ user 對齊決定要不要動 ── 命中可能在引用對話、反諷句、或本意如此，機械無法判斷、模型 sense 才能。

- 開頭命中 7.2 列的空泛開頭句式（「最近有一些想法 / 我想分享一件事 / 今天來談談」這類）── grep 命中後 sense 看開頭整段是否真的空泛
- 文章命中「你應該 / 你必須 / 你可以這樣做」這類強命令式教學語氣字眼 ── grep 命中後 sense 看是否在引用對話 / 反諷
- 文章命中「正能量 / 加油 / 不要放棄 / 相信自己 / 你值得 / 努力就會 / 終有一天 / 堅持下去」這類勵志公式字眼 ── grep 命中後 sense 看是否本意如此

> 註：spec v2.1 原本有第 4 條「沒有把全篇套進『我原本以為 X 後來發現 Y』這種單一固定句型機械填空」── 已移到 13.2，因為這是結構級判斷、不可機械檢。

## 13.2 sense 自審部分（user 在 Step 6 跟發文前最終裁定）

* 使用者覺得內容像自己
* 使用者願意承認這是自己想說的話
* 文章有真實問題
* 文章有思考路徑
* 文章有情緒或認知轉折
* 文章有具體洞見，不只是漂亮結論
* 文章不只是正確，而是有生命感
* 文章沒把全篇套進單一固定句型（譬如不是每段都是「我以為 X 後來發現 Y」變奏）── 這是結構級判斷、不可機械檢，由模型 sense + user 確認

## 13.3 兩組關係

13.1（機械訊號）只是初步偵測 ── 命中後**還要 sense + 上下文判斷**才算違規。命中不判死、命中可能合理（引用對話、反諷、本意如此）。

機械訊號的角色：幫 AI 不漏掉明顯紅旗（譬如「正能量、加油」這種勵志公式 AI 偶爾寫到自己沒注意 ── 機械掃一遍當提醒）。最終裁決靠模型語意 + 上下文 + user 對齊。

**13.1 是 reference signal、13.2 是 user 是否願意按發文鍵的 ground truth。**
